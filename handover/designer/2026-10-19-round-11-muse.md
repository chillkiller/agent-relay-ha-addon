## 2. Die DESIGN-Frage: Siehst du das UI noch als „typisch KI"?

**Kurz:** Ja — aber nicht wegen „zu wenig Features", sondern wegen **Surface-Sprache, die wie ein generisches Chat-Template wirkt**. Drei präzise Mängel:

### B-R11-1 — Identity-Card: generische Pillen-Ästhetik statt Charakter

- **Koordinaten:** [X: 8–155 / Y: 900–980] + Dropdown [X: 8–165 / Y: 800–890]
- **Pixel-Beleg:** Identity ist ein runder `G`-Avatar in `var(--accent)`-Coral + Name/Subtext in kleinem Monospace-ähnlichem Schnitt auf `var(--s1)`-Grund. Dropdown ist eine generische dunkle Bubble mit 3 Text-Zeilen + Icons. Zusammen wirkt das wie **jede AI-Chat-Sidebar** (Cursor/Discord-Klon) — keine eigene Material-Sprache.
- **Was fehlt der Surface-Sprache:** Keine Textur, kein Gewicht, kein Detail. Der Avatar ist ein farbiger Buchstabe statt eines identifizierbaren Zeichens (Facepile/Status-Ring/Gradienten-Rand). Die Card hat keinen **taktilen Anker** (z. B. leichtes Inset, Hairline-Rahmen, Subtle-Glow bei Online). Dropdown ist reine Text-Liste — kein Shortcut-Hint, kein Trenner, keine Ikonen-Hierarchie.
- **Erwartungssatz:** Nach Fix hat die Identity-Card eine eigene Materialität (z. B. dezenter `border: 1px solid var(--line)` + `inner shadow` oder Avatar mit echtem Bild/Initialen-Ring) und das Dropdown trägt eine **visuelle Signatur** (Trenner, Shortcuts, Hover-States), die nicht wie ein generiertes Template aussieht.
- **Checkliste:** [x] Live-CSS/Screenshot [x] HEX `--accent` Coral, `--s1` Dark [x] px-Spacing [x] Fonts Instrument Sans — **Befund belegt**.

### B-R11-2 — Nav-Gruppen-Sprache: kein Informations-Hub-Gefühl

- **Koordinaten:** [X: 8–155 / Y: 250–620] — RÄUME (7) + TEAM (7) im `roomscroll`
- **Pixel-Beleg:** Beide Gruppen benutzen identisches Muster: `▾ LABEL` + `count` + darunter gleichförmige Rows mit `# Name •`. Das ist **1:1 Slack/Discord-Generika**. Der Nutzer soll **Control-UI** fühlen (Informations-Dichte, Hierarchie, Favouriten), bekommt aber „noch eine Chat-App". Besonders: Codex-DM taucht als normale `#`-Row auf — kein visuelles Signal „das ist ein Direkt-Chat, kein Raum".
- **Was fehlt der Surface-Sprache:** **Hierarchische Differenzierung.** RÄUME und TEAM sehen gleich aus — gleiche Typo-Größe, gleiches Gewicht, gleicher Spacing. Keine **Dichte-Variation** (z. B. kompaktere TEAM-Chips vs. breitere Raum-Rows). Keine **Semantik-Farbe** (DM = andere Grundierung, Projekt-Raum = Badge, Ausgeladen = gedimmt). Das Auge findet keinen Anker — alles plätschert gleich.
- **Erwartungssatz:** Nach Fix haben RÄUME/DIREKT/PROJEKTE jeweils eigene visuelle Register (z. B. DM mit Avatar + Name statt `#`, Projekt mit 🗂-Badge farbig, Ausgeladen gedimmt/gekapselt) und die TEAM-Leiste ist als **Facepile** oder Chip-Grid dichter, nicht als 1:1-Kopie der Raum-Liste.
- **Checkliste:** [x] Screenshot belegt (7+7) [x] HEX aus Tokens [x] px/Spacing aus `styles.css` [x] Keine Commits — **Befund belegt**.

### B-R11-3 — Composition-Ruhe: Hauptfläche atmet nicht

- **Koordinaten:** [X: 200–990 / Y: 60–900] — gesamter Main-Bereich; [X: 260–940 / Y: 870–985] — Composer
- **Pixel-Beleg:** Main ist ein **einziger dunkler Leerraum** mit zentriertem Placeholder („Projekt-Raum bereit") + unten fixiertem Composer-Block. Kein Raster, keine Karten, kein „Dashboard spürt man". Selbst mit 7 Räumen wirkt die App wie ein leeres Chat-Fenster — nicht wie ein **Control-Center**, das Räume, Agents und Projekte orchestriert.
- **Was fehlt der Surface-Sprache:** **Kompositions-Autorität.** Control-UI lebt von **Dichte + Kanten** (Karten, Borders, Panels). Hier ist alles `background: var(--bg)` + `1px transparent`. Der Composer ist ein runder Pill-Block, der „schwebt" — kein Bezug zum Main (kein Separator, kein Inset). Header `Agent Relay — Review-Board…` mit Ellipsis auf 1440px verschwendet die Breite — **Titel wird gekürzt obwohl Platz da ist** (bereits aus Runde 10 bekannt).
- **Erwartungssatz:** Nach Fix hat Main eine **starke horizontale Struktur** (z. B. Header mit echtem Breadcrumb statt gekürztem String, Main mit subtilem Grid/Inset, Composer als in den Main integriert statt schwebend) und die Sidebar/Main-Trennung ist **nicht nur ein 1px Border**, sondern eine **Tiefenschicht** (z. B. `s1` vs. `bg` mit leichtem Kontrast).
- **Checkliste:** [x] Screenshot 1440×900 fullPage [x] Header-Ellipsis bei viel Breite belegt [x] Composer-Schatten/Abstand aus CSS [x] Kein Commit — **Befund belegt**.
