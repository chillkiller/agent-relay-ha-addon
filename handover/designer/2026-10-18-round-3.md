# Design Review — Round 3 (gemma4:31b-cloud)

## Befunde

1. **[X: 264-1920, Y: 56-112]** $\rightarrow$ **Tab-Leiste (Chat|Board) Kontrast** $\rightarrow$ Die aktive Tab-Fläche (`.room-tab.active`) nutzt `var(--s3)`, was auf dem `var(--canvas)` Hintergrund zu wenig Tiefe erzeugt. Der Fokus-Zustand wirkt flach.
   **Korrektur:** `.room-tab.active { background: var(--s2); color: var(--ink); box-shadow: inset 0 0 0 1px var(--line-2); }`
   **Erwartung:** Klarer, "gehobener" Aktiv-Zustand, der sich haptisch vom Hintergrund abhebt.

2. **[X: 264-1920, Y: 112-900]** $\rightarrow$ **Nachrichten-Dichte (Slack-Kompaktheit)** $\rightarrow$ Der vertikale Abstand zwischen den Nachrichten-Blöcken ist durch `gap: 2px` in `.messages` zwar gering, aber die `.msg .meta` Margin (`margin: 10px 0 2px`) erzeugt zu viel "Luft" bei Gruppen-Nachrichten. Die "Slack-Dichte" wird durch die Meta-Abstände untergraben.
   **Korrektur:** `.msg .meta { margin: 4px 0 2px; } .msg.group-first .meta { margin-top: 12px; }`
   **Erwartung:** Kompakterer Fluss innerhalb einer Nachrichtengruppe, während der Gruppenstart deutlich bleibt.

3. **[X: 264-1920, Y: 900-1000]** $\rightarrow$ **Composer Proportionalität** $\rightarrow$ Der Composer wirkt durch die Höhe der Textarea im Leerzustand und den massiven `box-shadow` nach oben (`0 -8px 20px`) zu dominant und "schwer" für eine reine Chat-Eingabe. Er bricht den Fluss der Canvas.
   **Korrektur:** `.composer { box-shadow: 0 -4px 12px rgba(0,0,0,.3); padding: var(--sp-2) var(--sp-6); }`
   **Erwartung:** Subtilere Integration in die Oberfläche, weniger visuelles Gewicht.
